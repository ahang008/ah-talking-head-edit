# 口播精剪规则

规则来自阿杭长期迭代的本人口播制作要求。当前请求优先于系列预设；不得把一个素材的特殊删留推广到全部素材。

## 语义和发音

- 先通读整片内容，按完整表达选重说中更完整的一遍，删除废弃半句、明确口误和无信息量前缀。正常自我介绍、结束语、限定语和支撑观点的演示保留。
- 判断分为 KEEP、DELETE、CHECK，逐项记录源区间和理由。没有完成判断的 CHECK 不得写成已验收。
- 那、那么、啊、嗯等只有孤立、拖长且不承担语义承接时才删除；不按词表批量删除。
- 低能量间隔超过 0.25 秒列候选，超过 0.4 秒优先复核，超过 0.8 秒逐个记录删留理由。数字是复查门槛，不是自动删除线。屏幕操作、强调、换段可以保留必要等待。
- 检查跨切口两侧累计空白，不能只检查单个片段内部。词内低谷、轻声和英文拼读间隔不得机械删除。
- 新切口核对前词尾音、后词起音和句意。先检查前后各约一秒的原声短窗，疑似吞字扩大范围。ASR、波形、静音扫描不能冒充听音；未听清的边界留 CHECK。
- `protected_speech` 只填写确已确认的有效发音，不用整个长段伪装逐词保护。不要为了通过检查删掉保护标记。

## 系列参数

- 当前用户参数最高优先；普通任务默认原速、无音乐。
- 阿杭 AI 博主和 IP孵化系列已有 1.2 倍速约定时沿用；同步重算声音和画面时间。配乐仅在本次已要求时加入。
- 不把不同系列的封面、配乐和归档互相套用。指定主题返工沿用原目录，保留源片和历史成片。

## 精剪完成门槛

整片语义、停顿候选、切口发音、最终字幕、实际画面和声音分别登记。只剪外围等待属于粗剪；生成 JSON、完整解码或静音报告通过，都不能称为精剪通过。实际听音不可用时明确缺项，并继续可完成的字幕、导出和机器检查，不虚构听音证据。

## 重复音频检查

- 出现 Star Star、同词连续两遍、回声或字幕连续重复时，先登记目标时间、前后剪口、素材身份和可听音轨，暂停把问题归因于识别错误。单条可见音轨不等于音频没有重复。
- 同时核对原视频内嵌声音、分离音轨、配音、嵌套片段和其他可听轨道。相同素材及源区间在目标轴重叠，通常提示重复混音；同一源区间被顺序使用两次，提示重复拼接。
- 回声型重复可表现为两个近似波形同时或短延迟出现、音量异常；重复拼接可表现为两个近似波形依次出现、相同声纹和呼吸底噪重复。波形相似只列候选，不能把正常重说或强调直接删除。
- 比对原片和工程引用素材，排除预处理素材自身已含叠音。核查实际音频流数量、音轨静音和音量状态；字幕同词重复只作为回查音频的信号。
- 结构检查按经核实的素材身份比较。相同音频被重新编码或换文件名时，哈希和 material 可能不同；原片自身重说、短延迟回声也可能无区间复用。结构报告无命中不能排除这些情况。建立同源别名需比对声纹/波形和素材来源，不凭文件名认定。
- 使用 `scripts/audio_audit.py` 检查实际读回并登记的可听片段清单。遗漏轨道时检查范围必须记为不完整。完整解码、无时间重叠和字幕识别通过均不能代替切口听音。
- 修复重复音频后重新计算时间线，并让剪映重新生成最终字幕；不沿用旧时间码，不仅删字幕里的重复字来遮盖声音问题。

片段清单是 JSON 数组，每项为 `material`（经核实的素材身份或哈希）、`source_start`、`source_end`、`timeline_start`、`timeline_end`（秒）和 `audible`（布尔值）。需要包含原片内嵌声及分离声等所有轨道。脚本只读检查，命中不自动删除；合法配音重叠仍需记录原因。
